# 运行与启动规范

> 适用：Arc for Avalonia（`net10.0`，Avalonia 12.1.5；`src/` 下 37 个工程：组件库 + Blocks + Gallery 文档站 + Docs 引擎 + Agent 层，另有 `tests/` 自检工程）。
> 本文只讲**怎么把东西跑起来**；设计/契约/门禁细节见 [`../README.md`](../README.md) 与 [`CONVENTIONS.md`](../CONVENTIONS.md)。

## 1. 一句话

Gallery 用 `dotnet run --project src\Apps\Arc.Avalonia.Gallery` 启动；构建一律走 `tools\build.ps1`（带锁）。
**不要双击** `src\Apps\Arc.Avalonia.Gallery\bin\Debug\net10.0\Arc.Avalonia.Gallery.exe`。

## 2. 标准命令

所有命令都在**仓库根目录**执行。

| 场景 | 命令 | 说明 |
|---|---|---|
| 构建整个解决方案（**标准**） | `pwsh -File tools\build.ps1` | 内部加 `.build.lock`（15 分钟超时）、`-m:1` 串行构建，避免多会话/多 agent 抢 obj 与内存爆掉 |
| 只构建 Gallery | `pwsh -File tools\build.ps1 -Project src\Apps\Arc.Avalonia.Gallery\Arc.Avalonia.Gallery.csproj` | |
| 启动 Gallery 窗口 | `dotnet run --project src\Apps\Arc.Avalonia.Gallery` | 等价于 README 的 `dotnet src\Apps\Arc.Avalonia.Gallery\bin\Debug\net10.0\Arc.Avalonia.Gallery.dll` |
| 打开指定页面 | `dotnet run --project src\Apps\Arc.Avalonia.Gallery -- --page button` | 参数见 §3 |
| 组件/契约自检 | `dotnet run --project tests\Arc.Avalonia.Tests` | 输出 `VERIFY: checks=N failures=0`（当前 190/0） |
| 一键门禁 | `pwsh -File tools\check-all.ps1` | 三态：GREEN / KNOWN-RED / RED / SKIP；**只有新增违规才 exit 1** |
| 截图 | `pwsh -File tools\shots.ps1 -Page button -Theme both` | 多了 `-Shell`、`-Width`、`-SkipBuild`、`-TimeoutSec` |
| 手机端 smoke | `pwsh -File tools\mobile-smoke.ps1` | 对应 `check-all.ps1` 的 R12（Gallery 尚无 `--mobile` 时 SKIP） |

> ⚠️ 不要用裸 `dotnet build ArcUI.slnx` 代替 `tools\build.ps1`：这个仓库常有多个 agent 并行构建，
> 裸 build 会撞 `.build.lock` 的保护边界，产生互相覆盖的 obj/中间产物。

## 3. Gallery 命令行参数

| 参数 | 作用 |
|---|---|
| （无） | 打开文档站首页 |
| `--page <slug>` | 直接打开某页（如 `button`、`chat`、`tokens`） |
| `--list` | 列出全部页面 slug 后退出 |
| `--audit` | 全目录完整性审计（294/294，0 错误） |
| `--smoke` | 逐页渲染冒烟（323 页，0 失败） |
| `--shot <dir> --page <slug> [--theme light\|dark] [--offset N] [--shell]` | 离屏截图 |

参数要放在 `--` 之后：`dotnet run --project src\Apps\Arc.Avalonia.Gallery -- --audit`。

## 4. IDE

- **Visual Studio 2026**：直接 `F5`（调试器走 `CreateProcess`，不会弹安全警告）。
- **Rider**：`Run` 可用；若 `Run`/`Debug` 一闪就退，是 Hot Reload 启动钩子被本机安全软件拦
  （同 WowGeometryDance 的已知问题），改用命令行。
- 只改组件库时不必每次起 Gallery，`tests\Arc.Avalonia.Tests` 的自检更快。

## 5. 为什么不能双击 exe

`bin\Debug\net10.0\Arc.Avalonia.Gallery.exe` 是 .NET 的 apphost，双击由资源管理器（ShellExecute）拉起，会经过：

| 检查 | 弹窗 | 触发条件 |
|---|---|---|
| 附件管理器（Mark-of-the-Web） | **打开文件 - 安全警告**（运行 / 取消） | 文件带 `Zone.Identifier` 数据流，且无有效数字签名 |
| SmartScreen 声誉 | **Windows 已保护你的电脑** | 未签名、无下载声誉的新 exe |

弹窗里的「发行商：未知发布者」「发送方：…」分别来自签名状态与 `Zone.Identifier` 的 `HostUrl` / `ReferrerUrl`。
该数据流不是浏览器专属：解压工具、云同步客户端、下载器、跨机拷贝都会盖。

`dotnet run` / `dotnet *.dll` / VS 调试器都直接 `CreateProcess`，不经过附件管理器，所以不弹——
这也是 README 一直写 `dotnet ...Gallery.dll` 而不是 `.\Gallery.exe` 的原因。

## 6. 确实需要双击时

```powershell
Unblock-File .\src\Apps\Arc.Avalonia.Gallery\bin\Debug\net10.0\Arc.Avalonia.Gallery.exe

Get-ChildItem .\src -Recurse -Include *.exe,*.dll -File | Unblock-File

Get-Content .\src\Apps\Arc.Avalonia.Gallery\bin\Debug\net10.0\Arc.Avalonia.Gallery.exe -Stream Zone.Identifier
```

要长期自愈，在 `Directory.Build.targets`（本仓库已有该文件）里加：

```xml
<Target Name="StripMarkOfTheWeb" AfterTargets="Build"
        Condition="'$(OS)' == 'Windows_NT' and '$(TargetExt)' == '.exe'">
  <Delete Files="$(TargetPath):Zone.Identifier" TreatErrorsAsWarnings="true" />
</Target>
```

## 7. 排障对照

| 现象 | 真实原因 | 处理 |
|---|---|---|
| 双击 Gallery exe 弹「打开文件 - 安全警告」 | MOTW + 无签名 | `Unblock-File`，或改用 `dotnet run` |
| 双击弹「Windows 已保护你的电脑」 | SmartScreen 声誉检查 | 同上 |
| `BUILD LOCK TIMEOUT` | 另一个会话/agent 正在构建 | 等它结束，或对单工程加 `-NoLock`（清楚自己在做什么再用） |
| `dotnet build` 后 XAML 报奇怪错误 | 与并行构建抢了 obj | 用 `tools\build.ps1` 重跑 |
| `check-all.ps1` 报 R5 RED | `artifacts/` 里没有 pack 产物 | 先 `dotnet pack`，再跑门禁 |
| IDE Run 一闪就退 | Hot Reload 启动钩子被拦 | 命令行 `dotnet run` |
